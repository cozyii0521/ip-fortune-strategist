# Cathy Reels 公式卡：選擇、剪裁與安全護欄

只在生成或審核 Cathy 的 Reels／短片時讀本檔。本檔優先於一般爆款公式：家庭護老內容必須保持私隱、專業邊界與非恐懼式溝通。

## 1. 先定「第一秒反應」，再選 Hook

| 觀眾第一秒反應 | 主機制 | 可用句式 | 適用內容 |
|---|---|---|---|
| 「講緊我」 | 身份代入 | `如果你係……`／`當你發現……` | 目標客自我辨識、照顧需要轉變。 |
| 「睇完有嘢攞走」 | 利益前置 | `出院前，有 3 條問題……` | 清單、交接、資源與提問框架。 |
| 「點解會咁？」 | 認知衝突 | `揀院舍之前，先唔好……` | 決策順序、常見誤解、觀點片。 |
| 「我唔知呢件事」 | 好奇心缺口 | `真正卡住你的，不是……` | 職業觀察、拆盲點。 |
| 「呢種感覺我明」 | 情緒場景 | `全家最攰嗰個人……` | 照顧者壓力、家庭分工、共鳴。 |
| 「然後呢？」 | 懸念 | `我整理完之後，先發現……` | Cathy 可公開的個人經歷或公開資料整理。 |

每條片只選一個主機制；最多加一個輔助機制。強 Hook 必須由正文合理承接，不能只為製造缺口。

## 2. 反常識的三步承接

只在能清楚解釋的情況下使用反常識。依序：先承認原本想法為何合理 → 拆解原有做法的限制或盲點 → 給一個更好的判斷標準、觀察方向或下一步。

例：`揀院舍之前，先唔好急住睇院舍。` → 家屬急著比較很自然 → 但未釐清父母的照顧需要，所有比較只會靠感覺 → 先列清功能、醫療、照顧者負荷與資源條件。

不要把反常識寫成未核實的因果、絕對後果或恐懼警告。

## 3. 內容類型與剪裁規則

| 類型 | 片內骨架 | 必要剪裁 | Cathy 適用題 |
|---|---|---|---|
| 知識型 | Hook → 核心因素／步驟 → 一句提醒 → 自然 CTA | 直接進問題或步驟；刪長背景與重複總結。 | 出院藥物交接、社工會面、家居安全。 |
| 觀點型 | Hook → 常見理解 → 為何不夠 → 更好判準 | 不急著教完整方案；保留觀點缺口。 | 需求先於院舍、內疚令決策拖延。 |
| 情緒／共鳴型 | 具體場景 → 說出未說出口的感受 → 一句重置 | 不硬塞清單或引流 CTA。 | 最攰照顧者、家庭會議失敗。 |
| 紀錄／示範型 | 最強畫面或結果 → 關鍵步驟 → 結果／延伸 | 先給結果可增加觀看；不必解釋所有準備。 | Cathy 整理「家庭照顧決策地圖」、自查表使用示範。 |
| 服務展示型 | 家屬卡位 → Cathy 如何整理問題 → 可得到的交付物 → CTA | 不把服務講成醫療處置或萬能解決方案。 | 1v1 諮詢、決策地圖、非同步篩選。 |

## 4. CTA 決策

CTA 的唯一任務是完成本片承諾，而不是每條都推銷。

| 影片結尾情況 | CTA 決定 |
|---|---|
| 知識片留有可延伸的檢查或清單 | 導向同一題目的自查表，例如留言「護老」。 |
| 觀點片已講透，但目的在建立立場 | 以總結句或一個問題收結；不強塞引流。 |
| 情緒共鳴片的力量在最後一句 | 停在共鳴句；最多用極輕的追蹤提示。 |
| 服務展示片已清楚說明交付物 | 導向四題篩選或預約；不可直接承諾處理個別臨床問題。 |

## 5. Hook 的鏡頭與語氣指令

| 機制 | 演繹方式 |
|---|---|
| 身份代入 | 直視鏡頭，如同點名；不要先自我介紹。 |
| 利益前置 | 語速俐落，第一句即交代成果或清單。 |
| 認知衝突 | 表情嚴肅、句子短；不要誇張嚇人。 |
| 好奇心缺口 | 略帶保留感，如同分享一個常被忽略的觀察。 |
| 情緒場景 | 語速放慢、畫面具體；不以煽情音樂代替內容。 |
| 懸念 | 五秒內進入關鍵事件；不用長鋪墊。 |

## 6. Cathy 家庭護老內容的優先護欄

1. 不用 `99%`、`九成人`、`一半人` 等無可核實來源的百分比。
2. 不用「你咁做會害咗父母」、「第二次跌倒就要付出代價」等恐懼與道德壓力句式。
3. 不用任何院友、家屬或工作個案作故事 Hook，即使已匿名。只講可泛化的職業觀察、個人公開經歷或公開資料。
4. 不下個別診斷、改藥、停藥、劑量、磨藥、傷口處置或急症判斷。教育內容只交付觀察、提問、轉介與決策方向。
5. 不把入院舍、居家照顧或請人包裝成孝與不孝。討論安全、承擔、需要與適合度。
6. 先核實每個醫療、社福、服務資格與數字聲稱；無法核實就改為一般原則或不說。

## 7. 交稿前的 7 項審計

1. 本片的唯一內容任務是甚麼？
2. 主 Hook 機制是甚麼？是否過度疊加？
3. Hook 的承諾有沒有在正文被交付？
4. 有沒有可刪的背景、準備或重複總結？
5. CTA 是否必要，而且只指向一個下一步？
6. 有沒有任何未核實數字、因果、個案或個別臨床指令？
7. Cathy 能否用本人語氣、本人專業責任說出每一句？
